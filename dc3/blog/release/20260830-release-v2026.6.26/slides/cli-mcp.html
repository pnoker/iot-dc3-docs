一条调用的四站链路
1
客户端发起
Claude / Cursor / dc3-cli / Agent 框架，携带 OAuth 令牌
2
网关 POST /mcp
JSON-RPC · RS256 验签 · scope 检查（由 RBAC 投影）
3
工具执行
落到 Agentic Center 受控工具面：查设备 / 读写点 / 命令辅助
4
结果与审计
确定数据原路返回 · 调用全程入审计账本
协议是新的，权限体系是旧的：工具封装自平台既有 API，智能体没有特权通道
令牌 TTL 阶梯
只读长有效期——查询类工具便利优先
常规中等有效期——点位读写按业务节奏
高危短有效期 + step-up——重新换取授权（强制执行接入中）
三行命令验证本版本：dc3 config set gateway → dc3 auth login → dc3 tools call · oauth 开关经 compose 透传（dc3.gateway.oauth.enabled）
