Release R2
消息总线换型
1起目标队列容器
podman compose -f dc3/docker-compose-*.yml up -d
2改 MQ 类型环境变量
DC3_MQ_TYPE=kafka # 默认 rabbitmq
3数据中心换依赖
<artifactId>dc3-mq-kafka</artifactId>
六适配器同跑 TCK 契约 · 行为等价有背书
时序库换型
1起目标存储容器
make up STACK=optional SERVICES="tdengine"
2改激活类型
DC3_TSDB_TYPE=tdengine # 默认 timescale
3数据中心换依赖
<artifactId>dc3-tsdb-tdengine</artifactId>
IoTDB 首启自动挂载微秒精度配置（必需）· 时区口径全家族 DEFAULT_ZONEID
关系引擎切换
1起对应数据库容器
mysql / mariadb 镜像按 compose 选择
2改数据源连接配置
DC3_DATA_DATASOURCE_URL=...
3初始化对应方言种子
initdb 种子按库方言提供
MariaDB 差异仅 VALUES() 写法 · collation 用 unicode_ci 两库通吃
✓兼容性：默认路径（RabbitMQ + TimescaleDB + PostgreSQL）行为不变，升级透明
✓开销可控：非默认适配器不引入则不打包——不为不用的组件付 jar 与启动成本
✓验证建议：切换后先以 Virtual 驱动验证链路，再切真实设备流量
发布口径：部署侧配置操作，业务代码零改动 · 命令与变量名以仓库 docs/mq-brokers.md、docs/tsdb-stores.md 为准
