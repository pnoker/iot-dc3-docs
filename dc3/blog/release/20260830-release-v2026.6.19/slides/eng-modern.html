IoT DC3 · Release R2 v2026.6.19 · 特性详解 3/3

底座现代化：pnpm / Pinia / Netty / Javadoc 四件小事

发版文章通常不讲这些——但底座的现代化速度，决定大特性落地时踩多少坑
包管理：npm/yarn → pnpm
全项目切换 pnpm lockfile，eslint / prettier 配置同步更新
视图组件随迁移重写——顺手清掉一代技术债
为什么：pnpm 的依赖去重与安装速度，对 CI 时长是直接收益
状态管理：Pinia 组合式 store
新增 auth / interval store 模块，老 store 迁移到 Pinia composition API
Vite 配置与依赖同步升级
为什么：组合式 API 与 Vue 3 心智一致，状态逻辑可测试、可复用
网络层：Netty API 现代化
UDP / TCP 服务从 NioEventLoopGroup 切换到 MultiThreadIoEventLoopGroup + NioIoHandler
废弃 EnvironmentPostProcessor 旧导入与 JsonMapper 引用更新
为什么：跟进上游 API 演进，别把废弃警告留到被迫大改的那天
知识沉淀：Javadoc 大波浪
驱动实现与入口类补齐详细 JavaDoc；字段命名一致性增强
auth / data / manager / single 应用类逐一注释
为什么：8 年项目的可读性就是贡献者门槛——注释工程是低成本高回报的投资
取向一句话：底座现代化与小特性同版本交付——大版本到来时，地基已经是新的
