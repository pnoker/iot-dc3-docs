v2026.9.15
Release R1
特性一 · 多协议接入
  • 36 个驱动模块：工业协议 17 · IoT 协议 7 · 数据桥接 5 · 基础通信 5 · 仿真调试 2
  • 驱动为独立微服务：按需启停、按需扩容，不用的驱动不参与部署
  • 统一建模 Driver → Device → Profile → Point，上层只见语义统一的点位
覆盖工厂自动化 / 电力 / 楼宇 / 水利主力协议面
特性二 · 云原生微服务
  • Java 21 · Spring Boot 4 · Spring Cloud 2025，网关统一入口
  • 服务间 gRPC + Protobuf；无状态设计支持水平扩展
  • Compose 一键起栈，另有 Swarm / Kubernetes / Helm 部署配置
center-single 单体形态为小规模场景省资源
特性三 · Driver SDK
  • 只写协议本身：报文解析 + 点位映射，注册/心跳/调度/上行由运行时承担
  • 驱动开发指南随文档站发布：docs.dc3.site · Driver Authoring
  • 新驱动 = 新镜像，注册即被平台统一管理
第 37 个驱动应该来自真实工位的真实需求
特性四 · 企业级基线
  • 租户隔离全链路：数据库 / 缓存键 / API 上下文 / 服务间 gRPC
  • JWT + Spring Security RBAC · TLS 传输加密 · 操作审计
  • Facade 边界 + DO/BO/VO 三层模型，跨服务调用不绑传输细节
双语在线文档 docs.dc3.site 随版本同步更新
