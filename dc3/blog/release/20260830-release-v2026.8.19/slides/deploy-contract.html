ID 全线字符串化 · 怎么做的
问题：JS Number 只能安全表示 2⁵³，雪花 ID 更长
1936547295000000000 (精度丢失)→"1936547295000000000" (string)
HTTP 契约统一以字符串下发标识符；前端按字符串解析、移除 json-bigint 补丁库（补丁库是症状治疗，契约收敛才是根治）；顺带修复 nanoid 高危通告（3.3.18）。 web 侧类型债同步清理：设备/驱动/详情模型从 {} as any 收敛为显式 Partial 类型。
为什么现在做：ID 精度问题在数据量上来后必然爆发，趁驱动大版本一起收敛，一次破坏、长期干净。
