最快验证路径 · 三行命令
$dc3 config set gateway <url>指向平台网关
$dc3 auth login取得 OAuth 令牌
$dc3 tools call <tool>调用 MCP 工具
dc3-cli 是独立的 TypeScript CLI：既是运维终端，也是给 Agent 框架与脚本用的 MCP 客户端
这条链路的两条设计原则
能力封装，不是旁路：MCP 工具背后是 Agentic Center 用的同一套受控工具面——不会因为换了协议而出现特权通道
快速迭代中的区域：工具清单、scope 细粒度、高危工具附加授权在陆续完善，以 docs 与仓库 design 文档最新状态为准
分水岭含义：过去对 AI 开放的深度取决于定制集成数量，现在实现一次 /mcp 就等于对所有 MCP 客户端开放
