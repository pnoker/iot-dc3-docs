# 控制台 · AI 助手

智能中心的对话界面就在 Web 控制台里：顶栏按钮打开右侧聊天面板，可以切全屏工作台；模型提供方和模型配置的管理页在 **设置 → 模型提供方 / 模型配置**（路由 `/settings/model/provider` 和 `/settings/model/config`）。工具面、两阶段确认和生产安全清单在 [Agentic 中心](../ai/agentic)，这页只讲界面。

> 你在这里：想在控制台里直接问 AI"哪台设备掉线了"。链路和安全模型看 Agentic 页，这里讲操作。

## 入口和布局

顶栏的启动按钮把聊天面板挂到右侧 dock，不跳页面，看设备列表的同时就能问。面板能展开成全屏工作台，长对话、来回切会话的时候用得上。

会话在左侧轨道里管理，搜索、分页、重命名、删除都在这。历史消息有本地缓存，翻回旧会话不用整段重拉。

输入框对中文输入法安全，组合期的按键不会把消息发出去；可以带附件。回复流式输出，随时中断或重试。

## 一轮回复长什么样

回复由若干卡片拼成，不是一整段文字：

| 卡片 | 出现时机 |
|------|---------|
| 工具步骤卡 | 模型每调一次内置工具（查设备、读位号、跑统计）都留一步，点开看入参和返回 |
| 图表块 | 模型产出可视化数据时内联渲染，折线、柱状、饼图、热力都有 |
| 引用与指标卡 | 回答里引用的实体、关键数字 |
| 附件卡 | 你上传的文件 |
| 动作确认卡 | 模型提议写位号这类高危动作时，唯一需要你点按钮的地方 |

动作确认卡就是两阶段确认的界面：提议先落成待确认的 Action（10 分钟过期），卡片上写清楚改哪个位号、写什么值，点确认才下发，点拒绝作废。

会话偏好（模型、温度、`maxTokens`、是否要求确认）跟着会话存，下一轮沿用。token 用量随响应带回来，这轮对话花了多少看得见。

## 设置 → 模型提供方

这页对应 `dc3_model_provider` 表：增删改提供方，类型分 OpenAI 兼容和 Anthropic。三条规则跟后端一致（详见[生产安全清单](../ai/agentic#生产安全清单)）：

1. `base_url` 必须是 HTTPS、解析到公网地址（SSRF 防护，没有白名单）；
2. API key 提交后 AES-256-GCM 加密落库，界面不再回显；
3. 改 `base_url` 必须同时换新的 API key。

每个提供方可以跑两级连通性检查（`provider/check`，结果有缓存）：L1 查"连得上吗、key 对吗"，L2 再查"模型看得见吗、真的能答吗"。结果按维度展示，最近一次的检查状态也标在列表上。

## 设置 → 模型配置

这页对应 `dc3_model_config` 表：把"某家提供方下的某个模型"登记成可选项，带能力开关（流式、工具调用、视觉、推理）和默认标记。会话偏好里的模型下拉来自这里；没有可用模型配置的租户拿到的是明确报错，不会静默落到共享的兜底模型上。这里也能跑连通性检查（`model/config/check`）。

## 界面动作对应的接口

| 界面动作 | 接口（经网关 `/api/v3/agentic`） |
|---------|------------------------------|
| 发消息 | `POST /chat/completions`（`stream=true` 走 SSE） |
| 会话搜索 / 重命名 / 删除 | `POST /session/list`、`POST /session/update`、`DELETE /session/delete` |
| 翻历史消息 | `POST /message/list`（请求体内分页） |
| 上传 / 删附件 | `POST /attachment/upload`、`DELETE /attachment/delete` |
| 确认 / 拒绝高危动作 | `POST /action/confirm`、`POST /action/reject` |
| 提供方管理与检查 | `GET/POST/DELETE /provider/*`、`POST /provider/check` |
| 模型配置管理与检查 | `/model/config/*`、`POST /model/config/check` |
